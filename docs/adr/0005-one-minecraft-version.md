# Support one Minecraft version for now

Only the latest Minecraft version is supported for now, because the mod is unreleased and every extra version multiplies the testing and porting work. This is a matter of timing: multiple versions will be supported in the future. The route is [Stonecutter](https://stonecutter.kikugie.dev/), which builds one jar per version from one source tree using comment-based conditionals, with a CI matrix per version.
