# Game rules hold the mod's settings

The mod's first settings (how far and how deep a mine grows, and how far a miner looks for its Mine Entrance) are integer game rules registered with Fabric API's `GameRuleBuilder`, in their own "Better Coppers" category. We chose them over a config file, a config library or a data pack because they need no new dependency or file format, check their own ranges, are saved per world, and can be changed with `/gamerule`, the world-creation screen, the in-world game rules screen and the dedicated server's management API. Values are only read on the server, so nothing has to sync to clients.

The cost: each rule is a single flat number, and an operator sets it once per world; there is no server-wide default file. Structured values (such as section weights) don't fit, so if one ever has to be configurable it goes in a data pack, not in a pile of rules. We also keep the list short on purpose: tuning numbers that are safety caps rather than taste (vein size, blocked-check thresholds) stay constants. Config libraries were ruled out because they lag behind Minecraft releases (owo-lib had no 26.3 build when we decided), and ADR 0005 has us follow each release.
