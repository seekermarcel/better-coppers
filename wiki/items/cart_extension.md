# Cart Extension

A **Cart Extension** turns a [Copper Chest Minecart](/items/copper_chest_minecart) into a double chest of 54 slots, keeping what is inside.

## Obtaining

<Recipe id="cart_extension" />

## Usage

Right-click a Copper Chest Minecart with it. One item is used up. A cart that is already a double chest refuses it.

## Behaviour

The extension drops again when the cart is broken, as long as the `entityDrops` game rule is on.
